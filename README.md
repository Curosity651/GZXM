# GZXM 重点项目科研管理系统（前端 Mock 原型）

本项目是面向一个固定重点项目的前端业务原型。重点项目下包含多个课题，科研指标、成果和月季报按课题办理；每个课题还可在归档模块中新建多个配套自筹项目。

## 本期能力

- 四类角色：系统管理员、项目技术负责人、科研助理、课题牵头单位；
- 每个课题独立业务账号和课题数据范围；
- 课题科研指标配置、指标完成监控和预警规则；
- 论文、专利、软著、标准的投稿/申请前预审及正式成果两级审批；
- 人才培养直接进入正式成果两级审批；
- 课题月报、季报六项模板、逾期标记及两级审批；
- 重点项目公共材料、课题国家材料、配套自筹项目三类归档；
- 科技项目、技改项目、基建项目归档清单；
- Mock 文件信息、审批记录、本地持久化和一键重置。

## 运行

```bash
npm install
npm run dev
```

默认开发地址由 Vite 输出。本地预览构建：

```bash
npm run build
npm run preview
```

## 验证

```bash
npm test
npm run lint
npm run build
```

## 数据说明

- 数据保存在浏览器 `localStorage`，key 为 `gzxm-research-management-v1`；
- “重置演示数据”会恢复内置课题、指标、成果、报告和归档示例；
- 上传文件只记录名称、数量和 Mock 标识，不保存到真实文件服务器；
- 前端角色与数据权限仅用于原型演示，不构成生产环境安全控制。

## 需求基线

完整业务规则见项目目录中的 `GZXM重点项目科研管理系统开发文档.md`。前端代码修改应以该文档的“已确认决策记录”为准。
