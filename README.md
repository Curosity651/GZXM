# 国家科技重大专项 - 科研成果管理系统

## 功能概览

- **科研成果管理**：录入、编辑、提交科研成果（学术论文、发明专利、软件著作权、标准规范、人才培养），支持论文状态/专利状态跟踪
- **成果审批**：审批人审核成果信息、佐证材料，系统自动校验指标匹配、重复检测、材料完整性，支持材料逐项审核
- **科研指标配置**：管理课题、时间节点、指标分解矩阵，支持批量编辑和 Excel 导出
- **预警规则配置**：配置时间预警、数量缺口预警、成果进度预警、佐证材料预警、国内期刊比例预警，黄/橙/红三级阈值
- **指标监控**：多视角（项目总体/按课题/按单位/按节点）查看指标完成情况、国内期刊比例、预警中心
- **用户管理**：系统管理员可管理用户账号、角色分配、密码重置、启用/禁用
- **角色权限**：系统管理员/项目管理人员/课题用户/成果审批人员，按角色过滤菜单
- **项目材料归档**：归档目录管理、材料上传/查询、归档进度监控

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 运行测试
npm run test

# 代码检查
npm run lint
```

## 角色权限说明

- **系统管理员**：拥有全部功能权限，包括用户管理
- **项目管理人员**：可管理科研指标配置、预警规则、成果录入、成果审批、材料归档及指标监控
- **课题用户**：可录入本课题的科研成果，查看所属课题的指标监控数据
- **成果审批人员**：可审批已提交的成果，审核佐证材料，查看指标监控

## 数据说明

- **Mock 数据**：系统内置了演示项目数据（课题、单位、时间节点、指标、成果、归档等）
- **本地存储**：用户数据和业务数据保存在浏览器 localStorage 中（key: `research-achievement-storage-v6`）
- **重置数据**：在系统右上角点击"重置演示数据"按钮可恢复到初始 mock 数据状态
- **文件上传**：采用浏览器本地 Mock 模式，文件实际存储为 Blob URL，刷新后失效

## 技术栈

- 前端框架：React 19 + TypeScript 6
- 构建工具：Vite 8
- UI 组件库：Ant Design 6 + @ant-design/icons 6
- 状态管理：Zustand 5（localStorage 持久化）
- 日期处理：dayjs
- 路由：React Router 7
- Excel 导出：xlsx
- 测试框架：Vitest 4

## 项目结构

```
src/
  components/       # 公共组件
    achievement/    # 成果表单字段组件
    layout/         # 布局组件（侧边栏、头部）
    AuthGuard.tsx   # 认证守卫
  data/             # Mock 数据
  pages/            # 页面组件
    achievement/    # 成果录入、成果审批
    admin/          # 用户管理
    archive/        # 归档管理
    indicator/      # 指标配置
    monitoring/     # 指标监控
    warning/        # 预警规则
  services/         # 服务层（认证、文件）
  store/            # Zustand 状态管理
  types/            # TypeScript 类型定义
  utils/            # 工具函数（统计、校验、预警、导出）
```
