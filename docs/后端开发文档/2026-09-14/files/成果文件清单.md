## 5. 初始 API 成果

当前代码已经定义：

```text
POST /api/v1/auth/login
GET  /api/v1/auth/me
GET  /api/v1/projects
GET  /api/v1/projects/{projectId}/units
GET  /api/v1/projects/{projectId}/topics
GET  /api/v1/topics/{topicId}
```

另外提供健康检查与 OpenAPI 入口：

```text
GET /actuator/health
GET /v3/api-docs
GET /swagger-ui.html
```

这些接口已有 Java 定义，但在 MySQL 驱动和表结构完成前不能作为完整运行结果验收。

## 6. 已知待处理事项

- `server/pom.xml` 仍需从 PostgreSQL 依赖切换为 MySQL 依赖。
- PostgreSQL 的 V1 迁移不能继续作为 MySQL 正式迁移使用。
- 根目录和 `server/` 下的部分 README、`.env.example` 仍描述 PostgreSQL，需要在数据库基础任务中统一更新。
- 前端 `localStorage` key 在 README、Mock service 和实际 store 中存在历史版本差异。
- 前端尚无真实 HTTP API client，也没有统一处理 JWT、401/403 和刷新登录状态。
- 当前开发机缺少运行工具链，后续必须在统一环境执行测试和启动验证。
