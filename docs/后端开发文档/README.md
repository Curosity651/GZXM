# 重点项目科研管理系统后端开发文档

本文件夹集中保存前后端协作、接口契约和数据库设计资料。

## 建议阅读顺序

| 顺序 | 文档 | 用途 |
|---:|---|---|
| 1 | [完整后端开发计划](./完整后端开发计划.md) | 当前主计划，统一业务口径、三人分工、阶段、协作和验收规则 |
| 2 | [后端协作与架构方案](./backend-collaboration-plan.md) | 了解架构、模块边界和技术选择的详细说明 |
| 3 | [API接口清单](./api-reference.md) | 以表格方式评审各业务模块的接口和使用权限 |
| 4 | [MySQL数据表说明](./mysql-data-dictionary.md) | 以表格方式理解27张数据表及其业务关系 |
| 5 | [OpenAPI机器契约](./openapi.yaml) | 用于生成接口文档、客户端代码、服务端骨架和Mock服务 |
| 6 | [MySQL建表脚本](./mysql-schema.sql) | 用于正式创建MySQL基础表结构 |

## 文件使用说明

- 产品和项目负责人主要阅读前三份Markdown文档。
- 前端和后端开发人员以`openapi.yaml`作为接口联调契约。
- 数据库开发人员以`mysql-schema.sql`作为建表基础，并通过Flyway管理后续变更。
- 归档文件存储暂时保持存储服务抽象，不要求本阶段确定或连接MinIO。
