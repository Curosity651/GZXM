# 进度管理模块重构设计

## 1. 目标与范围

进度管理模块只保留三个页面：

1. 月季报提交
2. 月季报审批
3. 月季报进度

本期只实现前端 Mock 原型，不连接后端。规则、任务、报告和审批记录保存在现有 Zustand/localStorage 状态中。本次不修改成果、科研指标、预警和归档模块。

## 2. 核心业务颗粒度

一份月报或季报的唯一业务颗粒度为：

```text
课题 + 报告类型 + 年度 + 期次
```

一个课题无论有多少承担单位，每个报告期只产生一份报告，由该课题的牵头单位填写和提交。课题承担单位不产生月季报任务，也不能代替牵头单位提交。

## 3. 角色与数据范围

### 系统管理员

- 可以查看三个页面及全部课题报告数据。
- 默认没有规则配置、报告提交或业务审批按钮。

### 项目技术负责人

- 查看全部课题的月季报及提交进度。
- 负责月季报终审。
- 不能修改月季报规则。

### 科研助理

- 查看全部课题的月季报及提交进度。
- 配置全项目统一的月报规则和季报规则。
- 负责月季报初审。

### 课题牵头单位

- 只查看本单位牵头课题的月季报任务。
- 填写、保存草稿、提交、查看审批意见和修改退回报告。
- 一个单位牵头多个课题时，分别办理每个课题的报告。

### 课题承担单位

- 不提交月季报。
- 不显示“月季报提交”入口。
- 当前模块不提供需要其操作的业务功能。

## 4. 月季报提交页面

页面面向课题牵头单位。系统根据统一规则、当前日期和用户牵头的课题生成可见任务。

页面分为月报、季报两个页签。列表字段包括：课题、报告期次、开放时间、截止时间、报告状态、时效状态、提交时间和操作。

报告状态包括：未填报、草稿、初审中、终审中、已通过、退回修改。

操作规则：

- 未到开放时间：只显示任务，不允许填报。
- 开放时间内：允许创建或编辑草稿并提交。
- 超过截止时间仍未提交：允许补交，标记为逾期。
- 初审中、终审中和已通过：报告只读。
- 退回修改：牵头单位可修改并重新提交。

报告沿用当前六项内容模板：里程碑完成情况、总体进展、示范工程进展、经费使用、下期工作、问题及措施。

## 5. 月季报审批页面

月季报采用两级审批：

```text
课题牵头单位提交
  → 科研助理初审
  → 项目技术负责人终审
  → 已通过
```

科研助理只看到“初审中”的待办；项目技术负责人只看到“终审中”的待办。审批人可以查看课题、期次、牵头单位、提交时间、是否逾期、完整报告内容和历史审批意见，并执行通过或退回。

退回后统一回到“退回修改”，由课题牵头单位修改并重新提交，再次进入科研助理初审。

## 6. 月季报进度与规则页面

页面包含“提交进度”和“规则配置”两个页签。

### 6.1 提交进度

按课题统计月报和季报任务情况。支持按报告类型、年度、期次和状态筛选。

统计卡片包括：应提交课题数、已提交数、已通过数、未提交数、逾期数和提交率。列表展示每个课题的牵头单位、报告状态、提交时间、审批阶段和时效状态。

提交率按以下方式计算：

```text
已提交数 ÷ 应提交课题数 × 100%
```

“已提交”包括初审中、终审中、已通过和退回修改；草稿与未填报不计入已提交。

### 6.2 规则配置

全项目只配置一套月报规则和一套季报规则，对所有课题统一生效，不允许课题单独设置日期。

月报规则字段：

- 是否启用
- 生效年度
- 每月开放填报日
- 每月截止提交日

季报规则字段：

- 是否启用
- 生效年度
- 季报月份，默认 3、6、9、12 月
- 季末月开放填报日
- 季末月截止提交日

开放日与截止日均按自然日处理，截止日不得早于开放日。当配置日期超过当月实际天数时，自动取当月最后一天。

科研助理可编辑并保存规则；其他可见角色只读查看。保存规则后，前端根据规则为全部启用课题生成或更新对应报告任务，不覆盖已经提交的报告内容和审批状态。

## 7. 页面导航与权限

进度管理导航固定为：

- 月季报提交
- 月季报审批
- 月季报进度

各入口仍由 RBAC 页面权限控制。页面内部的提交、初审、终审和规则配置按钮由操作权限控制；业务数据再根据课题牵头关系过滤。

## 8. 原型演示方式

- 使用 `topic01` 登录：演示课题牵头单位填报课题一月报或季报。
- 使用 `assistant` 登录：演示统一规则配置、全部课题进度和初审。
- 使用 `leader` 登录：演示全部课题进度和终审。
- 使用 `unit01` 登录：进度管理中不出现月季报提交入口。
- 使用 `admin` 登录：可以只读查看进度页面，但不显示规则保存和审批按钮。

## 9. 验收条件

- 导航中进度管理只显示三个约定页面。
- 每个课题每一期只有一个月报任务或一个季报任务。
- 只有课题牵头单位可以填写和提交其牵头课题报告。
- 课题承担单位没有月季报提交入口。
- 科研助理配置统一规则并进行初审。
- 项目技术负责人进行终审。
- 月季报进度能按照规则统计全部课题的未提交、已提交、已通过和逾期情况。
- 系统管理员默认只读，不参与配置、提交或审批。
- 不新增或运行自动化测试，仅执行构建和人工页面验证。
